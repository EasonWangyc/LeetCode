## 哈希

哈希共有`unordered_map`和`unordered_set`两种数据结构，前者以pair的形式出现，存在键和值两个元素，常用于以$O(1)$时间根据键查找对应的值；后者常用于以$O(1)$时间判断某个元素是否存在。

当暴力解是 $O(n^2)$、且瓶颈卡在"对每个元素再扫一遍找某个东西"时，用哈希把那次扫描换成 $O(1)$ 查找。代价是 $O(n)$ 空间，以及"按 key 无序"。

### 技巧

- 使用`unordered_set<int> set1(nums1.begin(), nums1.end());`可以将vector快速转换成哈希集合结构
- `mp.count()`判断是否包含某个元素

### 模板

```cpp
unordered_map<K, V> mp;
unordered_set<V> set;
for(auto& x : nums){
    if(count){/*更新答案*/};
    /*插入元素*/
}
```

## 双指针

这类问题通常需要两个指针，通常用于线性的数据结构中。

### 技巧

分为左右指针和快慢指针两类。

- 左右指针：两个指针从两端或中间出发，直至满足特定条件
- 快慢指针：从起点出发以不同逻辑同向而行

### 模板

```cpp
// 快慢指针
int l = 0, r = 0;
for(int r = 0; r < n; r++){
    /*两者的更新逻辑*/
}
// 左右指针
int l = 0, r = n - 1;
while(l < r){
    /*逻辑*/
}
```

|题目|描述|思路|注意事项|链接|
|---|---|---|---|---|
|移动零|将数组中所有0移到末尾同时保持其他元素相对位置|**快慢指针**：用一个cur变量表示非零元素个数然后填充对应元素|最后需要使用`fill()`|[移动零](./TwoPointer/283_moveZeros.cpp)|
|盛水最多的容器|找到两条线使得中间部分面积最大|**左右指针**：每次移动的是两者中元素值小的那个|面积计算时使用`r-l`|[盛水最多的容器](./TwoPointer/11_maxArea.cpp)|

## 滑动窗口

滑动窗口其实就是一个满足条件的队列，通过循环判断是否满足特定去更新左右指针和答案。

### 技巧

可以分为固定长度与不固定长度两类：

- 固定长度：一层循环+判定条件
- 不固定长度：一般是l和r两个指针，循环r，根据条件判断l是否移动

### 模板

```cpp
// 固定长度k
for(int r = 0; r < n; r++){
    // 更新元素
    int l = r - k + 1;
    // 判断
    // 更新l
}
// 不固定长度
for(int r = 0; r < n; r++){
    // 更新元素
    // 判断
    // 更新l
}
```

### 原题整理

|题目|描述|思路|注意事项|链接|
|---|---|---|---|---|
|无重复字符的最长子串|返回s中包含不重复字符的最长子串的长度|**不固定长度的滑动窗口+双指针+哈希表**：初始化左指针，遍历右指针，用一个哈希表记录每个字符出现的次数，判断当前窗口是否满足每个字符的出现次数均为1，否则右移左指针直至满足条件，更新ans|右移左指针时需要使用`while`来保证最后所有元素的出现次数均为1|[无重复字符的最长子串](./SlidingWindow/3_lengthOfLongestSubstring.cpp)|
|找到字符串中所有字母异位词|在s中找到所有p的异位词，返回下标|**固定长度的滑动窗口**：先用一个数组记录p中每个字符出现的次数，然后使用一个滑动窗口在s中遍历，每次移动右指针r时更新窗口中字符的出现次数，左指针为l，如果当前窗口中的字符出现次数与p中字符出现次数相同，则说明找到了一个字母异位词，记录下起始索引l。每次增加r位置元素对应的哈希表数值，减少l位置元素对应的哈希表数值。|直接初始化大小为26的两个int数组，顺序表示字母，判断条件是`==`；添加时使用`c-'a'`；l的边界条件判断|[找到字符串中所有字母异位词](./SlidingWindow/438_findAnagrams.cpp)|

|滑动窗口最大值|固定大小的滑动窗口在数组中滑动，返回每次窗口中的最大值|**双端队列+滑动窗口**：保存下标，保证队首元素对应的nums[i]值大于队尾元素对应的值，遍历右指针r，`pop_back()`的逻辑是如果末尾元素小于当前元素，则它后续不可能再是最大值，直接丢弃；左指针为r-k+1,`pop_front()`的逻辑是队首下标小于l，当l满足大于等于0时开始往ans中push答案|ans数组的大小是`n-k+1`|[滑动窗口最大值](./SubString/239_maxSlidingWindow.cpp)|
|最小覆盖子串|给定s和t，返回s中的包含t的每个字符的子串|**哈希表+滑动窗口**：初始化两个哈希表need和window，key为字符，value为出现次数，遍历t得到need，维护一个valid表示window和c中相同字符出现的次数相同的次数，后续的判断关键是看遍历s的元素c，如果need包含c，`window[c]++`，判断valid是否可以增加，后续`while()`判断valid是否等于need的长度，满足时移动l并更新window直到不满足条件，记录此时的左右指针|初始化len需要包含`<climits>`头文件；最后需要使用`substr`，需要包含`<string>`头文件|[最小覆盖子串](./SubString/76_minWindow.cpp)|
