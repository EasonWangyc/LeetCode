## 哈希

哈希共有`unordered_map`和`unordered_set`两种数据结构，前者以pair的形式出现，存在键和值两个元素，常用于以$O(1)$时间根据键查找对应的值；后者常用于以$O(1)$时间判断某个元素是否存在。

当暴力解是 $O(n^2)$、且瓶颈卡在"对每个元素再扫一遍找某个东西"时，用哈希把那次扫描换成 $O(1)$ 查找。代价是 $O(n)$ 空间，以及"按 key 无序"。

技巧：

- 使用`unordered_set<int> set1(nums1.begin(), nums1.end());`可以将vector快速转换成哈希集合结构
- `mp.count()`判断是否包含某个元素

### 模板

```cpp
unordered_map<K, V> mp;
unordered_set<V> set;
for(auto& x : nums){
    if(count){/*更新答案*/};
    /*插入元素*/
}
```

## 双指针

这类问题通常需要两个指针，通常用于线性的数据结构中，可以分为左右指针和快慢指针两类。

技巧：

- 左右指针：两个指针从两端或中间出发，直至满足特定条件
- 快慢指针：从起点出发以不同逻辑同向而行

### 模板

```cpp
// 快慢指针
int l = 0, r = 0;
for(int r = 0; r < n; r++){
    /*两者的更新逻辑*/
}
// 左右指针
int l = 0, r = n - 1;
while(l < r){
    /*逻辑*/
}
```

## 滑动窗口

滑动窗口其实就是一个满足条件的队列，通过循环判断是否满足特定去更新左右指针和答案，可以分为固定长度与不固定长度两类。

技巧：

- 固定长度：一层循环+判定条件
- 不固定长度：一般是l和r两个指针，循环r，根据条件判断l是否移动

### 模板

```cpp
// 固定长度k
for(int r = 0; r < n; r++){
    // 更新元素
    int l = r - k + 1;
    // 判断
    // 更新l
}
// 不固定长度
for(int r = 0; r < n; r++){
    // 更新元素
    // 判断
    // 更新l
}
```

## 图论

图可以理解为一系列点组成的结构，主要分布在两类载体上：**网格图（二维矩阵）**和**抽象图（邻接表/邻接矩阵）**。

解题方法通常有深度优先搜索和广度优先搜索两种方式。深度优先搜索（DFS）和广度优先搜索（BFS）是用于遍历或搜索图与树的两种最基础的算法，它们的核心区别在于搜索的方向与使用的底层数据结构。

两者做的是同一件事：从一个点出发，沿着边把所有能到达的点都走一遍，每个点只访问一次，唯一的区别是下一个访问对象，DFS用栈（递归），BFS用队列。BFS**按层扩散**，所以第一次到达某个点时走的一定是最少步数。当题目出现“最短/最少几步”时，需要使用BFS。

### 模板

连通型/标记型DFS：

```cpp
void dfs(Node* u){
    // 1. 递归出口与非法边界校验（推荐放在入口处统一拦截）
    if (!u || isVisited(u) || isInvalid(u)) {
        return;
    }

    // 2. 标记当前节点已访问
    markVisited(u);

    // 3. 递归遍历所有邻接/后继节点
    for (Node* v : getNeighbors(u)) {
        dfs(v);
    }
}
```

回溯型DFS：

```cpp
void backtrack(Node* u, State& state, vector<Result>& ans) {
    // 1. 终止条件：找到可行解或触碰边界
    if (isGoal(state)) {
        ans.push_back(state.currentResult());
        return;
    }

    // 2. 遍历当前节点的全部可行选择
    for (Node* v : getValidChoices(u, state)) {
        // [做选择]：更新状态
        state.apply(v);

        // [递归下潜]
        backtrack(v, state, ans);

        // [撤销选择]：回溯，恢复现场
        state.revert(v);
    }
}
```

BFS：

```cpp
int bfs(Node* start) {
    queue<Node*> q;
    unordered_set<Node*> visited; // 或使用 bool 数组 / 原地标记

    // 1. 初始化起点（单源或多源在此全部 push 进去）
    q.push(start);
    visited.insert(start);

    int step = 0; // 记录扩散层数 / 步数

    // 2. 队列循环
    while (!q.empty()) {
        int sz = q.size(); // 核心：固定当前层的节点数量

        // 遍历当前层的所有节点
        for (int i = 0; i < sz; ++i) {
            Node* cur = q.front();
            q.pop();

            // 检查是否到达终点
            if (isTarget(cur)) {
                return step;
            }

            // 扩展下一层的所有邻接节点
            for (Node* next : getNeighbors(cur)) {
                if (!visited.count(next) && isValid(next)) {
                    visited.insert(next); // 关键：入队时立刻标记，避免重复入队爆内存
                    q.push(next);
                }
            }
        }
        step++; // 整层扩展完毕，步数加 1
    }

    return -1; // 无法到达目标
}
```

## 回溯

回溯（Backtracking）本质上是带**状态撤销**的穷举型深度优先搜索（DFS），核心在于搞清楚树形结构的选择机制以及如何保证状态恢复的对称性。

通常需要一个变量来避免重复选取，一般使用`startIndex`或`used`数组来强行规定选取的顺序，避免生成重复的组合。

### 模板

```cpp
void backtrack(参数, int startIndex, vector<bool>& used, 状态变量, vector<vector<int>>& ans) {
    // 1. 终止条件（出口）
    if (满足终止条件) {
        ans.push_back(当前收集到的路径); // 收集结果
        return;                         // 大多数情况需要 return，子集问题除外
    }

    // 2. 单层遍历逻辑：横向枚举当前层的所有可能选择
    for (int i = startIndex; i < 数据集长度; ++i) {
        // [剪枝]：排除无效分支（提前停止或跳过）
        if (当前选择不合法 || 需要去重) continue; // 或 break

        // [做选择]：记录当前节点的选择
        path.push_back(nums[i]);
        updateState();

        // [递归下潜]：纵向往树的更深层探索
        backtrack(参数, 下一层起点(如 i+1 或 i), 状态变量, ans);
        // 如果使用数组一般直接引用对应数组即可

        // [撤销选择]：回溯，完全恢复现场！
        path.pop_back();
        revertState();
    }
}
```

## 二分查找

二分查找的本质是在具有“两段性（单调性）”的解空间中，通过排除不可能的一半来快速逼近答案。

### 模板

模板一：闭区间`[l,r]`

使用场景：**精准匹配数值**。区间均为待查合法元素，循环条件是`l<=r`，由于有`target==nums[mid]`判断，更新规则需要严格跨越：`r=mid-1`、`l=mid+1`。

```cpp
int binarySearchClosed(const vector<int>& nums, int target) {
    int l = 0, r = nums.size() - 1;
    
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] == target) {
            return mid; // 命中目标直接返回
        } else if (nums[mid] < target) {
            l = mid + 1; // 排除左半区及 mid
        } else {
            r = mid - 1; // 排除右半区及 mid
        }
    }
    return -1; // 未找到
}
```

模板二：全开区间`(l,r)`

使用场景：**查找大于等于 target 的左边界（等价于 std::lower_bound）**。区间内部才是待查合法元素，循环条件是`l+1<r`，退出时必定满足`l+1==r`，更新规则无脑赋值：`r=mid`、`l=mid`。

```cpp
// 寻找第一个 >= target 的元素下标（lower_bound）
int lowerBoundOpen(const vector<int>& nums, int target) {
    int l = -1, r = nums.size(); // 开区间保护边界
    
    while (l + 1 < r) {
        int mid = l + (r - l) / 2;
        // 染色规则：满足条件的给右侧，不满足的给左侧
        if (nums[mid] >= target) {
            r = mid; // mid 可能是答案，缩至右边界
        } else {
            l = mid; // mid 严格小于 target，缩至左边界
        }
    }
    // 循环结束：l + 1 == r
    // r 必定是第一个 >= target 的位置（若 r == nums.size() 说明全数组都 < target）
    return r;
}
```

模板三：左闭右开区间`[l,r)`

使用场景：**寻找极值**。区间逐渐向一个点压缩，循环条件`l<r`，退出时必定满足`l==r`，由于`mid`本身可能是极值候选，因此更新规则为`r=mid`、`l=mid+1`。

```cpp
int findPeakOrMin(const vector<int>& nums) {
    int l = 0, r = nums.size() - 1;
    
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] > nums[r]) {
            l = mid + 1; // 极值一定在 mid 右侧
        } else {
            r = mid;     // mid 自身可能是极值，不能写 mid - 1
        }
    }
    return nums[l]; // 跳出时 l == r，正好是目标单点
}
```
